# Portfolio working rules

- Read `VOICE.md` before writing or changing any visitor-facing copy. Apply the
  same first-person voice across all pages and both portfolio modes.
- Preserve verified career facts, dates, team attribution, and project scope.
- Check tech icons against the actual background in default, hover, and keyboard
  focus states. Single-color marks may be normalized; do not flatten multicolor
  badges into solid blocks.
- Before publishing, run the build, tests, lint, and asset audit. Verify the Git
  SHA, provider deployment status, and live bundle/assets after the push.
