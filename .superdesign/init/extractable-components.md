# Extractable Components

## Header

Shared desktop/mobile navigation with view switcher and contact actions.

## ParticlePortrait

Canvas2D photo-derived particle surface. Pointer position drives yaw, pitch, parallax, and local repulsion; idle time supplies subtle breathing motion. The image fallback remains available for reduced motion or Canvas failure.

## Reveal

Reusable viewport-once Motion wrapper for page sections. It must preserve semantic children and reduce to static content when reduced motion is requested.

## ActivityHeatmap

Local GitHub contribution snapshot with year selection and compact statistics.

## ProjectCard

Shared project record presented in home, professional, index, related, and detail contexts.
