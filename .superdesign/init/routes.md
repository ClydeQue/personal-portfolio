# Routes

- `/` Personal or Professional home, selected by the persistent view preference.
- `/about` narrative and evidence.
- `/projects` project index.
- `/projects/:slug` project case study.
- `/experience` career path.
- `/collection` curated local resources.
- `/blog` portfolio case-study notes.
- `/blog/:slug` case-study note detail.
Navigation is implemented by the local router in `src/app/router.js`.
