# Theme

The visual system is monochrome editorial UI with one electric-blue accent. Surfaces are white/off-white, borders are thin neutral gray, typography is dense and modern, and spacing follows compact 4/8/12/16/24/32/48px steps.

```css
:root {
  --accent: #1f4cff;
  --ink: #444;
  --ink-strong: #292929;
  --muted: #777;
  --rule: #dedede;
  --paper: #fafafa;
}
```

Motion is restrained: short opacity/translate entrances, small interactive lifts, and a continuously subtle particle portrait. Reduced-motion preference disables non-essential movement.
